# STOP 策略消融

## 正式协议

- 清洗数据批次：`results/stop_policy/20260718_221141`
- seed 9、17、29，共9次训练，全部完成。
- 只比较 `min_actions_before_stop=0/1/2`，三组均不使用 stop margin。
- 验证集有 374 条记录，其中 15 条为单标签；测试集有 6 条单标签。

## 验证集结果

| 最少输出数 | Sample F1 | Supported Macro-F1 | Exact Match | 漏选率 |
|---:|---:|---:|---:|---:|
| 0 | 0.7813 +/- 0.0050 | 0.5340 +/- 0.0073 | 0.2496 | **0.1886** |
| **1** | **0.7841 +/- 0.0018** | 0.5351 +/- 0.0084 | 0.2585 | 0.1887 |
| 2 | 0.7826 +/- 0.0011 | **0.5442 +/- 0.0240** | **0.2629** | 0.1907 |

允许空集与至少输出1个的漏选率仅差 0.0001，但后者 Sample F1 更高，
并且避免输出空证候集。至少2个的 Supported Macro-F1 均值最高，但误差也最大，
且会对所有单标签病例强制多报一个标签。综合模型表现和任务合法性，选择至少1个。

## 最终选择

```python
min_actions_before_stop = 1
stop_margin_threshold = None
```

输出第1个证候要素后，STOP 与其余未选标签直接按 Q 值竞争。行为选择、
Double DQN bootstrap 和推理使用同一合法动作掩码。

## 测试集报告

至少1个方案的 Sample F1 为 0.7966 +/- 0.0077，Supported Macro-F1 为
0.4158 +/- 0.0207。测试集上0个方案的均值更高，但测试集不参与策略选择。
