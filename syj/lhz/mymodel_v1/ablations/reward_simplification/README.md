步成本 0 与 0.02 的误差范围重叠；既然固定步成本没有稳定优势，最终选择
更简洁、且 Supported Macro-F1 更高的无步成本方案。

## 最终奖励

训练集标签支持度定义固定权重：

```text
raw_weight(k) = (N / (K * count_train(k))) ^ 0.5
weight(k) = mean_normalize(clip(raw_weight(k), 0.75, 2.0))
```

对预测集合 `S` 和真实集合 `Y` 计算加权 F1 效用 `U(S,Y)`。选新标签时：

```text
r_t = 0.95 * U(S_(t+1), Y) - U(S_t, Y)
```

选择 STOP 时：

```text
r_stop = U(S_t, Y)
```

最终配置为 `reward_beta=1.0`、`step_cost=0`、`weight_min=0.75`、
`weight_max=2.0`、`weight_power=0.5`。好奇心、动态误选惩罚和长度奖励不进入
主奖励，避免重复计分与非平稳目标。
